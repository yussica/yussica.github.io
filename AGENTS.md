# Agents

This document outlines the agents that can be used to interact with this project.

## Content Creator

The Content Creator agent is responsible for creating new blog posts and pages. It can be used to:

- Create new blog posts from a given title and content.
- Create new pages from a given title and content.
- Add metadata to posts and pages, such as tags and categories.

## Content Editor

The Content Editor agent is responsible for editing existing blog posts and pages. It can be used to:

- Update the content of a blog post or page.
- Update the metadata of a blog post or page.
- Fix typos and grammatical errors.

## Site Manager

The Site Manager agent is responsible for managing the overall site. It can be used to:

- Update the site's configuration.
- Manage the site's navigation.
- Add or remove social media links.
