# Context

This document provides context for the project.

## Overview

This project is a personal blog built with Jekyll and hosted on GitHub Pages. The blog is used to share information about living in Tokyo, with a focus on saving money.

## Technical Details

- **Site Generator:** Jekyll
- **Theme:** [Beautiful Jekyll](https://github.com/daattali/beautiful-jekyll)
- **Hosting:** GitHub Pages
- **Dependencies:**
    - jekyll
    - jekyll-remote-theme
    - jekyll-admin
    - webrick

## Content

The blog contains posts about various topics, including:

- Banks in Japan
- Investments
- Payment methods in Japan
- Point sites
- Preparation for living in Japan
